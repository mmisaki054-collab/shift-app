LINEの中のブラウザではダウンロードできません。下の「Chromeで開く」を押してください。
📥 Androidアプリをダウンロード Chromeで開く

入れ方(1分)

  1. 上のボタンを押す(「危険なファイル」と出たら「続行」)
  2. 通知欄の「shift-techo.apk」をタップ
  3. 「この提供元のアプリを許可」をONにして戻る →「インストール」
  4. 「Playプロテクトでブロック」と出たら「詳細」→「インストールする」
  5. 開いて、勤務先と時給を登録すれば使えます

Android専用です。iPhoneには入りません。

「アプリはインストールされていません」と出る場合: 古い版(10/8以前に入れたもの)が残っています。一度アンインストールしてから入れ直してください(その版のデータは消えます。以後の更新は上書きできます)。

できること

カレンダーに時間と金額を表示 ／ パターン1タップ入力・曜日まとめ入力 ／ 深夜・残業・交通費つき給料計算 ／ 掛け持ち対応 ／ 締め日・給料日 ／ 年収の壁の診断 ／ 希望シフトをLINEで提出 ／ 前日の通知 ／ 予定の登録 ／ グループでシフト共有

データは端末の中だけに保存されます。
